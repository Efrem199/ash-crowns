# Пепельные короны / Ash Crowns

Лёгкая браузерная кликер-стратегия на русском. Три расы, четыре типа зданий, шесть территорий, контртактики, указы, исследования и постоянные улучшения между династиями.

## Запуск

Нужен Node.js 20 или новее. Без установки зависимостей:

```sh
npm start
```

Открыть http://127.0.0.1:4173. Проверки: `npm test`.

Для GitHub Pages выбрать Settings → Pages → Deploy from a branch → main → / (root). Статические файлы index.html, style.css, app.js и engine.js работают на любом HTTP-хостинге. Открытие через file:// не поддерживается из-за ES modules.

## Механики

Люди строят дешевле на 20%, эльфы получают на 60% больше дерева и на 30% дешевле исследуют, дворфы добывают на 35% больше золота и имеют +20% силы армии. Старт: 35 золота, 10 дерева. Строй шахту, лесопилку, казармы; набирай армию, меняй указы и контртактику. Обход побеждает Натиск, Оборона побеждает Обход, Натиск побеждает Оборону. Победа гарантирована при силе не меньше обороны врага. Потери: 28% при победе, 15% при поражении. Производство без вкладки ограничено двумя часами.

После двух территорий можно возродиться: число осколков равно захваченным землям, а полная победа приносит ещё 5. Сбрасывается весь прогресс забега; осколки и три ветки вечных улучшений остаются. Можно выбрать другую расу.

Автосохранение в localStorage каждые 5 секунд, экспорт и импорт JSON. Сохранения локальны для браузера и origin; переносить между адресами через экспорт. Это одиночный прототип, сохранения можно редактировать, серверной защиты нет. Баланс предварительный.
